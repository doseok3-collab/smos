# SMOS Lab website

Soft-matter Optical Spectroscopy Laboratory, Department of Physics, Sogang University.

- Edit `content.py` (research, members, news) or `pubs.json` (publications), then run `python3 build.py` to regenerate `index.html`.
- Hosted with GitHub Pages at https://smos.sogang.ac.kr (see `CNAME`).
- The old SMOS wiki is preserved on the Internet Archive (Wayback Machine).
