# SMOS Lab 홈페이지

서강대학교 물리학과 Soft-matter Optical Spectroscopy Laboratory (김도석 교수)

## 내용 고치는 법

1. `content` 폴더에서 고칠 파일을 엽니다.
   - `home.md` 대문 제목과 소개 글
   - `research.md` 연구 주제
   - `publications.md` 논문 목록
   - `people.md` 구성원, 졸업생 (Alumni)
   - `news.md` 뉴스
   - `contact.md` 연락처
2. 오른쪽 위 연필 아이콘(Edit)을 누르고 고칩니다.
3. **Commit changes** 를 누르면 1~2분 뒤 사이트에 반영됩니다.

## 사진 바꾸기

같은 이름의 파일을 다시 올리면 바뀝니다 (Add file → Upload files).
- `main.jpg` 대문 사진, `profile.jpg` 교수 사진, `logo.png` 로고

## 디자인

`index.html` 은 사이트의 틀입니다. 디자인을 바꿀 때만 고칩니다.
